# FlappybirdClone
I recreated the famous classic game "Flappy Bird" using JavaFX as a personal project in order to practice my programing skills.
## Description 🎮
In this project I simulate the game´s mechanics where the player has to control a bird which has to dodge obstacles, in this case pipes, in order to gain the highest score. 
## Features
  - Basic physics (gravity and jump)
  - Automatic generation of pipes
  - Score system
  - Colisions
  - Simple HUD
  - Game restart after losing
## Used technologies
- JavaFX
