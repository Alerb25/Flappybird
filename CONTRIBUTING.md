# Contributing to Flappybird

First off, thank you for considering contributing to **Flappybird**! 
Whether you are fixing a bug, adding new features, improving documentation, or optimizing performance, your help is welcome.

## Code of Conduct
Please ensure a welcoming and inclusive environment for everyone. Treat all contributors with respect and maintain polite, constructive communication in issues and pull requests.

---

## How Can I Contribute?

### Reporting Bugs
If you find a bug in the game or codebase:
1. **Check existing issues** to make sure the bug hasn't already been reported.
2. Open a **New Issue** if your problem is unique.
3. Include clear details in your issue report:
   - **Title**: Short and descriptive summary.
   - **Environment**: Your OS, browser version, runtime environment, or hardware specs (if applicable).
   - **Steps to Reproduce**: Clear, step-by-step instructions.
   - **Expected vs. Actual Behavior**: What should happen vs. what actually happens.
   - **Screenshots/GIFs**: Visual aids are always appreciated!

### Suggesting Enhancements
Have an idea for a new feature, updated graphics, sound effects, or mechanic improvements?
1. Open a **New Issue** with the **Feature Request** or **Enhancement** label.
2. Clearly describe the feature and why it would be beneficial to the game.
3. Discuss the feature with the maintainer before starting work to align on the project's direction.

### Submitting Pull Requests
1. **Fork** the repository and create your branch from `main`.
2. Make your changes locally.
3. Ensure your code is clean, readable, and properly formatted.
4. Test your changes locally to confirm nothing is broken.
5. Push your branch to your fork and submit a **Pull Request (PR)** against the `main` branch.
6. Provide a descriptive title and detailed summary in your PR description.
