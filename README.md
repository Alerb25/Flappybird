# FlappybirdClone
Un clon del clásico juego Flappy Bird, desarrollado en JavaFX como proyecto personal para practicar programación.
## Descripción 🎮
En este proyecto recreo la mecánica del juego donde el jugador controla a un pájaro que debe esquivar obstáculos, en este caso tuberías, para conseguir la mayor puntuación posible.
## Características
  - Física básica (gravedad y salto)
  - Generación automática de los obstáculos
  - Sistema de puntuación
  - Detección de colisiones
  - Interfaz simple
  - Reinicio del juego tras perder
## Tecnologías utilizadas
- JavaFX
